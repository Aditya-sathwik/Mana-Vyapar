**Mana-Vyapar** is a premium B2B SaaS platform designed to bridge the gap between traditional merchants and the digital marketplace. It provides merchants with an all-in-one ecosystem to create, manage, and scale their digital storefronts while offering customers a seamless shopping experience via web and WhatsApp.

---

## ✨ Core Vision

Mana-Vyapar aims to empower every merchant with a "Mini-Amazon" — a highly responsive, personalized storefront. By simplifying the transition to digital, we enable merchants to reach customers wherever they are, whether it's through a custom domain or a dedicated WhatsApp bot.

---

## 🚀 Key Features

### 🏢 Merchant Mission Control
- **Seamless Registration**: Quick onboarding for new merchants.
- **Secure Payments**: Integrated payment gateway for subscription and feature unlocking.
- **Inventory Management**: Comprehensive panel to add, edit, and manage goods with ease.
- **Digital Khata Ledger**: Track credit and transactions within the platform.

### 🌐 Mini-Amazon Storefront
- **Instant Storefront**: Automatically generates a responsive, high-performance shopping website.
- **Shareable Micro-URLs**: Create short, professional links for social sharing.
- **Custom Domains**: Offer merchants the ability to brand their store with a custom domain name.
- **Full Checkout Flow**: Integrated cart, inventory sync, and secure checkout process.
- **Premium UI**: 3D elements and smooth animations powered by Three.js and Framer Motion.

### 🤖 WhatsApp Bot Integration
- **Direct Ordering**: Customers can browse products and place orders directly via WhatsApp.
- **Automated Support**: AI-driven responses for order tracking and product inquiries.
- **Merchant Sync**: Orders from WhatsApp are instantly synced with the merchant dashboard.

## 🛠 Tech Stack

### Frontend
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/), [GSAP](https://gsap.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) (React Three Fiber/Drei)
- **State Management**: [Redux Toolkit](https://redux-toolkit.js.org/)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)

### Backend
- **Runtime**: [Node.js](https://nodejs.org/)
- **API**: [Express.js](https://expressjs.com/)
- **Database**: [MongoDB](https://www.mongodb.com/) with Mongoose
- **Cloud Assets**: [Cloudinary](https://cloudinary.com/) (images)
- **AI Integration**: [OpenAI](https://openai.com/) (for bot intelligence)
- **PDF Generation**: [PDFKit](http://pdfkit.org/) (for invoices and manifests)

## 📦 Installation & Setup

### Prerequisites
- Node.js (v18+)
- MongoDB (Local or Atlas)
- Cloudinary & OpenAI API Keys

### Backend Setup
1. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file based on `.env sample`:
   ```bash
   cp ".env sample" .env
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

### Frontend Setup
1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
